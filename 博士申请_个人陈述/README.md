# 个人陈述（精简段落版）

本项目以 Swapnil Gandhi 的 GitHub 项目 **SoP-Template** 为排版参考，原项目采用 CC0-1.0 许可：
https://github.com/Swapnil-Gandhi/SoP-Template

## 本次调整

- 将各部分相邻短段落合并，正文段落块由86个减少到32个。
- 寄语压缩为4个核心段落，约为原长度的一半。
- 主标题与左侧页眉均使用“个人陈述”，并删除右上角学校页眉。
- 增加章节标题防孤行控制。
- 当前成品为 A4 四页，无文字越界。

## 文件

- `main.tex`：排版、申请人信息、页眉页脚。
- `content.tex`：正式个人陈述正文。
- `个人陈述-马睿骁.pdf`：已编译预览。
- `build.ps1`：Windows 下用 XeLaTeX 编译。
- `LICENSE.md`：模板许可说明。
