# 马睿骁学术简历 AltaCV 工程

本工程以 `D:\3_申博\2.docx` 为基础内容，使用 GitHub 上的 [AltaCV](https://github.com/liantze/AltaCV) 官方模板重新设计。

## 设计特点

- 双栏学术简历布局
- 墨蓝、青绿和金色学术配色
- 研究方向与经历为主栏，教育、技能和荣誉为信息侧栏
- 个人学术主页二维码
- 中英文标题及图标化联系方式

## 编译

在 PowerShell 中运行：

```powershell
.\build.ps1
```

需要 XeLaTeX。编译结果为 `马睿骁-学术简历.pdf`。
