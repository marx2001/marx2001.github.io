## 量子力学形式理论·个人学习笔记

**主题：从线性代数理解量子力学形式理论，并建立与第一性原理计算的联系。**

本文整理学习过程中形成的正确认识及讨论后的必要修正，重点在于理解各概念的物理意义和相互关系，而非具体数学推导。

## 一、希尔伯特空间、态矢量与表象

**核心理解：** 量子态可以看作矢量，基底就是一组基矢，一个矢量在不同基底下有不同的表示方式。

- 希尔伯特空间是具有内积且完备的矢量空间，是描述量子态的数学空间。
- 态矢量 `|ψ⟩` 是描述纯量子态的抽象矢量；波函数是态矢量在具体表象下的表示，如位置表象 `ψ(x) = ⟨x|ψ⟩`。
- 表象变换本质上是基底变换。改变基底只改变同一个量子态的数学表示方式，不改变其物理状态。
- 内积是普通点乘的推广，结果是标量（可以是复数），用于描述两个态矢量之间的重叠；叉乘则产生矢量，在三维空间中其方向垂直于原来两个矢量构成的平面。

## 二、算符、本征态与本征值

**核心理解：** 算符可以理解为线性代数中的线性变换；本征值和本征矢分别对应线性代数中的特征值和特征向量。

本征值方程：

`Â|φₙ⟩ = aₙ|φₙ⟩`

- 算符作用于本征矢量后，只改变其标量倍数，不改变其所张成的一维子空间；这个倍数就是本征值。
- 本征态是相对于特定算符而言的一种特殊量子态。一般量子态可以在该算符的完备本征态基底下展开，但不一定是该算符的本征态。
- 同一个算符更换基底后，其矩阵表示和本征矢的坐标分量可以改变，但本征值不变。
- 可观测量对应自伴算符，其本征值代表可能的测量结果，本征态代表具有相应确定测量值的状态（此处以离散谱为例）。

**需要区分：** 算符作用于一般态矢量是一种线性变换，不等于将其直接投影到某个本征态上，也不等于完成一次物理测量。

## 三、厄米算符与厄米共轭算符

**核心理解：** 厄米共轭算符是对原算符进行厄米共轭运算得到的算符，而厄米算符是满足原算符与其厄米共轭算符相等的一类算符的统称。

在正交归一基底的矩阵表示中，厄米共轭就是复共轭与转置：

`A† = (A*)ᵀ`

厄米算符满足：`Â† = Â`。

厄米性是一种数学性质，而不是某种特定的物理功能。自旋算符、位置算符、动量算符、哈密顿算符等是按照物理功能命名的；厄米算符则是按照数学性质命名的。

厄米算符的本征值为实数，不同本征值对应的本征态相互正交，这些性质适合描述物理可观测量。严格来说，无穷维空间中的可观测量要求算符具有自伴性，有限维情况下自伴与厄米等价。

## 四、正交性、归一性与完备性

- 正交性：不同基矢的内积为 0，彼此没有投影重叠。
- 归一性：每个基矢与自身的内积为 1，即模长为 1。
- 完备性：一组基矢足以表示整个空间中的任意矢量；无穷维空间还需要考虑级数的收敛。

**施密特正交化：** 将一组线性无关的矢量转化为相互正交的矢量，同时保持它们张成的空间不变。其几何本质是减去在已有基矢上的投影。对于厄米算符，同一本征值对应的线性无关本征态可以通过正交化得到仍属于该本征值的正交本征态；不同本征值对应的本征态天然正交。

正交归一化的目的不是改变物理状态，而是使矢量分解更加方便。选择完备的正交归一基底后，可以直接通过内积得到展开系数。

**狄拉克正交归一化：** 将离散谱的正交归一规则推广到连续谱的广义本征态。

- 离散谱：`⟨φₘ|φₙ⟩ = δₘₙ`，同一归一化基矢的内积为 1，不同基矢的内积为 0。
- 连续谱：`⟨p|p′⟩ = δ(p − p′)`，不同标签对应的广义本征态正交；归一条件由狄拉克 δ 函数的积分性质给出，而不是令相同标签的内积等于 1。

狄拉克正交归一化并没有将连续本征态离散化。普通可平方积分的连续波函数仍可进行通常的归一化；需要 δ 归一化的是连续谱中无法按普通方式归一化的广义本征态。

## 五、哈密顿量、薛定谔方程与定态

**核心理解：** 哈密顿量描述系统的能量规律，不是一个固定的能量数值；研究不同物理系统，需要构建相应的哈密顿量。

经典力学中，对于通常的动能加势能系统：

`H(x,p) = p²/(2m) + V(x)`

量子力学中，将位置和动量替换为相应算符，得到哈密顿算符。哈密顿算符既描述能量，也决定量子态的时间演化。

- 含时薛定谔方程：`iħ ∂|ψ⟩/∂t = Ĥ|ψ⟩`，描述量子态的时间演化，求解时需要给定初态。
- 定态薛定谔方程：`Ĥ|ψₙ⟩ = Eₙ|ψₙ⟩`，求解能量本征值和能量本征态。
- 定态：对于不显含时间的哈密顿量，能量本征态随时间演化只改变整体相位，物理状态保持不变。定态不代表粒子静止。

构建哈密顿量不能随意添加项，必须考虑自由度、物理相互作用、系统对称性、厄米性和合理近似。有效模型的参数可以通过理论推导、第一性原理计算或实验确定。

## 六、广义统计诠释

**核心理解：** 通过算符就能得到对应物理量的测量概率和统计平均值，这就是广义统计诠释的基本作用。

可以将其理解为对已知量子态的反向分解。以离散非简并谱为例：

1. 选择想研究的可观测量算符 `Â`，求出其本征态 `|φₙ⟩` 和本征值 `aₙ`。
2. 将已知量子态在这组完备的本征态基底下展开：`|ψ⟩ = Σₙ cₙ|φₙ⟩`。
3. 通过内积获得概率振幅 `cₙ = ⟨φₙ|ψ⟩`，对应测量概率 `Pₙ = |cₙ|²`。
4. 计算统计平均值：`⟨A⟩ = ⟨ψ|Â|ψ⟩ = Σₙ aₙPₙ`。

算符决定可能的测量结果和本征态，原量子态决定各个本征态的展开系数，广义统计诠释赋予展开系数概率意义。简并时，同一本征值对应的概率需要合并；连续谱则使用概率密度及积分。

**薛定谔方程解决的是如何获得量子态及其演化，广义统计诠释解决的是如何利用量子态获得物理测量信息。** 二者不是同一个过程。

## 七、不确定性原理与对易关系

**对易关系：** `[Â,B̂] = ÂB̂ − B̂Â`。若对易子为 0，则两个算符作用顺序可以交换，不影响最终的算符运算结果。

广义不确定性原理将位置—动量的不确定性关系推广到任意两个可观测量：

`ΔA ΔB ≥ (1/2)|⟨[Â,B̂]⟩|`

两个算符对易时，通常可以选取共同本征态，使两个可观测量同时具有确定值；两个算符不对易时，一般不能同时确定，但不代表所有量子态的不确定度乘积下限都大于零。

**能量—时间不确定性：** `ΔE Δt ≥ ħ/2`（以动力学形式为例）。时间通常是参数而非普通可观测量算符，此处的 `Δt` 是可观测量发生显著变化的特征时间，不是时钟的测量误差。能量不确定度与量子态演化速率存在联系；不确定性来源于量子态本身，而不是测量仪器精度不足。

## 八、广义埃伦费斯特定理

**核心理解：** 广义埃伦费斯特定理研究任意可观测量的统计平均值如何随时间变化。

`d⟨A⟩/dt = (1/iħ)⟨[Â,Ĥ]⟩ + ⟨∂Â/∂t⟩`

若算符不显含时间且与哈密顿算符对易，其期望值守恒；若不对易，则期望值可能随时间变化。

该定理放在不确定性原理一节，是因为它可以将可观测量与哈密顿算符的对易关系转化为期望值的时间变化率，再结合广义不确定性原理，推导出能量—时间不确定性关系。

它也是联系量子力学与经典力学、静态物性与动力学研究的理论基础之一。材料计算中可以将其与含时 DFT 等方法联系起来研究动力学，但它不是直接计算材料寿命的公式，静态 DFT 本身也不能直接给出寿命。

## 九、与第一性原理计算的联系

**核心理解：** 能带由能量本征值构成，计算能带的本质就是在不同波矢 k 下求解哈密顿量的本征值问题。

晶体势具有空间周期性。根据布洛赫定理，将普通的晶体哈密顿算符转换为含波矢 k 的形式，即可求解不同 k 点的能量本征值。波矢不是人为添加的相互作用，而是由晶体平移周期性引出的量子态标记。

Kohn–Sham 方程是一种有效单电子哈密顿量的本征值方程：

`Ĥ_KS(k)|uₙₖ⟩ = εₙ(k)|uₙₖ⟩`

常规 DFT 能带计算首先通过自洽计算确定与电子密度一致的有效哈密顿量，再固定相应有效势，沿高对称 k 路径求解本征值。Kohn–Sham 本征值形成计算得到的能带，但并不严格等价于真实多电子体系的全部激发能量。

- 本征值用于研究能级和能带色散。
- 本征态用于进一步分析自旋期望值、轨道投影及拓扑性质。
- 紧束缚模型和有效自旋模型则通过选取相关自由度及相互作用，建立适合特定研究问题的哈密顿量。

二维和三维量子力学的基本原理相同，区别主要在空间自由度及其引起的物理性质差异。二维晶体的能带依赖面内波矢，三维晶体的能带依赖三维波矢；二维材料中电子的自旋仍然可以具有三个方向的分量。

## 十、整体知识逻辑

| 理论知识 | 解决的问题 |
| --- | --- |
| 希尔伯特空间 | 量子态存在于什么数学空间？ |
| 表象理论 | 如何在不同基底下表示量子态？ |
| 算符理论 | 如何描述物理可观测量？ |
| 本征值与本征态 | 可观测量可能具有哪些确定数值？ |
| 哈密顿量与薛定谔方程 | 如何建立系统的能量模型并求解量子态？ |
| 广义统计诠释 | 如何从量子态获得测量概率及统计平均值？ |
| 广义不确定性原理 | 不同可观测量之间存在什么量子约束？ |
| 广义埃伦费斯特定理 | 可观测量的平均值如何随时间演化？ |

**量子力学的核心研究思路：** 构建哈密顿量 → 求解薛定谔方程 → 获得能量本征值和本征态 → 选择可观测量算符 → 利用广义统计诠释获取物理信息。

形式理论的核心不是学习一套全新的数学，而是将线性代数中的矢量、基底、线性变换、本征值与本征矢等概念推广到希尔伯特空间，并赋予其量子力学的物理意义。
