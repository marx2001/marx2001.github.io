## 格里菲斯量子力学·4.3 角动量

**主题：角动量的量子化、本征值与本征函数。**

本节是形式理论在轨道角动量问题中的具体应用，主要研究角动量算符的对易关系、允许的测量结果及其对应的本征态，也为后续理解自旋和自旋轨道耦合（SOC）打下基础。

## 一、角动量算符

经典力学中的角动量是位置矢量与动量矢量的叉乘：

`L = r × p`

量子力学中，将位置和动量替换为对应的算符，就得到轨道角动量算符：

`L̂ = r̂ × p̂ = −iħ(r × ∇)`

**核心理解：** 角动量算符是一种可观测量算符，用于研究量子态的轨道角动量性质。与线性代数中的矩阵类似，可以通过求解其本征值方程获得允许的测量结果。

## 二、角动量的对易关系

角动量的三个分量之间不对易：

- `[L̂x, L̂y] = iħL̂z`
- `[L̂y, L̂z] = iħL̂x`
- `[L̂z, L̂x] = iħL̂y`

因此，非零轨道角动量的三个方向分量不能同时具有确定值。

但是，角动量平方算符 `L̂² = L̂x² + L̂y² + L̂z²` 与各个方向的分量算符分别对易，例如：

`[L̂², L̂z] = 0`

**核心理解：** 可以同时确定角动量的大小和某一个指定方向上的分量，通常选择 z 方向。对易关系使这两个算符可以选取共同的本征态。

## 三、角动量的本征值与量子化（4.3.1）

角动量平方算符和 z 分量算符的本征值方程分别为：

`L̂²|l,m⟩ = l(l+1)ħ²|l,m⟩`

`L̂z|l,m⟩ = mħ|l,m⟩`

| 量子数 | 取值范围 | 物理意义 |
| --- | --- | --- |
| 角量子数 l | 0, 1, 2, … | 决定角动量大小 √[l(l+1)]ħ |
| 磁量子数 m | −l, −l+1, …, l | 决定角动量的 z 分量 mħ |

对于给定的 l，m 有 `2l+1` 个允许的取值。例如，p 轨道对应 l=1，允许的 m 为 −1、0、1。

**核心理解：** 角动量的大小及其沿指定方向的分量只能取特定数值，这就是角动量量子化。这些数值来源于角动量算符的本征值问题，而不是人为规定的。

### 升降算符

`L̂₊ = L̂x + iL̂y`

`L̂₋ = L̂x − iL̂y`

升算符使 m 增加 1，降算符使 m 减少 1，l 保持不变；到达相应的上限或下限时，继续作用得到零矢量。

升降算符是推导角动量本征值和构造本征态的数学工具，其作用不等同于实际的物理跃迁。

## 四、角动量的本征函数（4.3.2）

球谐函数 `Yₗᵐ(θ, φ)` 是轨道角动量平方算符与 z 分量算符的共同本征函数。

- 4.1 节：球谐函数是三维中心势场薛定谔方程的角向解。
- 4.2 节：球谐函数描述氢原子轨道的角向分布。
- 4.3 节：球谐函数具有确定的轨道角动量大小和 z 分量。

对于氢原子，哈密顿算符、角动量平方算符及 z 分量算符两两对易，因此可以选取它们的共同本征态 `ψₙₗₘ = Rₙₗ(r)Yₗᵐ(θ, φ)`。三个量子数 n、l、m 分别标记能量、轨道角动量大小及其 z 分量。

## 五、与材料计算的联系

轨道角动量是理解轨道磁矩、轨道极化及自旋轨道耦合的重要基础。在常见的原子型有效模型中，自旋轨道耦合可以写为：

`Ĥ_SOC = λ L̂ · Ŝ`

其中，L̂ 是轨道角动量算符，Ŝ 是自旋算符。在真实晶体中，晶体场和其他相互作用可能破坏连续旋转对称性，因此原子轨道的 l、m 不一定是严格守恒的量子数。

## 六、本节总结

**角动量算符 → 对易关系 → 共同本征态 → 本征值与角动量量子化 → 球谐函数。**

本节的重点是理解为什么角动量的三个分量不能同时确定，以及为什么角动量大小和一个方向的分量可以同时确定。升降算符及球谐函数的具体推导属于数学求解过程。

一般角动量的代数理论允许整数和半整数角动量，而普通轨道角动量只允许整数。这为下一节 4.4 自旋的学习提供了理论基础。

*学习依据：David J. Griffiths、Darrell F. Schroeter, Introduction to Quantum Mechanics, 3rd ed., §4.3 Angular Momentum；根据本次章节讨论整理，材料计算部分为延伸理解。*

## 格里菲斯量子力学·4.4 自旋

**主题：自旋的物理意义、矩阵表示、磁场中的自旋及角动量叠加。**

自旋与轨道角动量遵循相同的角动量代数规律，但物理来源不同。轨道角动量来自粒子的空间运动，自旋则是粒子的内禀角动量，并不是粒子绕自身轴线进行经典旋转。

## 一、自旋 1/2（4.4.1）

### 1. 自旋量子数与自旋态

自旋平方算符 Ŝ² 与自旋 z 分量算符 Ŝz 可以选取共同本征态：

`Ŝ²|s,mₛ⟩ = s(s+1)ħ²|s,mₛ⟩`

`Ŝz|s,mₛ⟩ = mₛħ|s,mₛ⟩`

电子的自旋量子数 s=1/2，磁量子数 mₛ=±1/2。因此，沿任意指定方向测量电子自旋分量，只有 +ħ/2 和 −ħ/2 两种可能结果。

以 z 方向的自旋本征态为基底：

- `|↑⟩ = (1, 0)ᵀ`：自旋向上。
- `|↓⟩ = (0, 1)ᵀ`：自旋向下。

任意纯自旋态可以表示为：

`|χ⟩ = a|↑⟩ + b|↓⟩ = (a, b)ᵀ`

其中 a、b 为复数，归一化条件为 `|a|² + |b|² = 1`。

**核心理解：** 自旋向上和向下是选定测量方向后的两个本征态，相当于二维复矢量空间中的两个基矢。电子的自旋态可以是它们的叠加，并不意味着电子只能处于这两个状态之一。二维自旋空间也不等同于二维真实空间。

### 2. 自旋算符与泡利矩阵

对于自旋 1/2 粒子，自旋算符可表示为 `Ŝᵢ = (ħ/2)σᵢ`，其中 σᵢ 是泡利矩阵。

| 泡利矩阵 | 矩阵形式（分号表示换行） |
| --- | --- |
| σx | `[0, 1; 1, 0]` |
| σy | `[0, −i; i, 0]` |
| σz | `[1, 0; 0, −1]` |

自旋算符是厄米算符，三个方向的分量之间不对易，例如 `[Ŝx, Ŝy] = iħŜz`。因此，自旋 1/2 粒子的不同方向自旋分量不能同时具有确定值。

根据广义统计诠释，对于上述归一化自旋态，沿 z 方向测量得到 +ħ/2 和 −ħ/2 的概率分别为 `|a|²` 和 `|b|²`，自旋期望值为：

`⟨Ŝz⟩ = ⟨χ|Ŝz|χ⟩ = (ħ/2)(|a|² − |b|²)`

**核心理解：** 泡利矩阵就是自旋算符在特定基底下的矩阵表示。选择不同的自旋算符，就可以研究同一个量子态在不同方向上的自旋性质。这是形式理论中表象、本征值和广义统计诠释的具体应用。

## 二、磁场中的电子（4.4.2）

### 1. 自旋磁矩与 Zeeman 劈裂

电子的自旋具有对应的磁矩：

`μ̂ₛ = −gₛμB Ŝ/ħ`

其中 gₛ 为电子自旋 g 因子，μB 为玻尔磁子。由于电子带负电，其自旋磁矩方向与自旋方向相反。

磁矩与外磁场的相互作用可以写成 Zeeman 哈密顿量：

`ĤZ = −μ̂ₛ · B`

对于仅考虑自旋与均匀外磁场相互作用的电子，当磁场沿 z 方向时：

`ĤZ = (gₛμB B/ħ)Ŝz`

两个自旋本征态的能量分别为 ±gₛμB B/2，能级差为 `ΔE = gₛμB B`（B 为磁场大小）。外磁场使原本简并的自旋能级发生劈裂，即 Zeeman 劈裂。

**核心理解：** 外磁场与自旋磁矩的相互作用改变了系统的哈密顿量，从而改变其能量本征值。这就是通过外磁场调控自旋能级的基本原理。

### 2. Larmor 进动与 Stern–Gerlach 实验

- **Larmor 进动：** 在均匀静磁场中，若自旋态具有垂直于磁场的期望值分量，自旋期望值会围绕磁场方向进动，角频率大小为 `ωL = gₛμB B/ħ`。这可以通过含时薛定谔方程或广义埃伦费斯特定理得到。
- **Stern–Gerlach 实验：** 非均匀磁场对不同磁矩分量产生不同的力，使粒子束发生离散分裂。经典实验采用银原子束，体现了角动量分量的空间量子化。

**核心理解：** Zeeman 劈裂研究磁场对能量的影响，Larmor 进动研究磁场对自旋时间演化的影响，Stern–Gerlach 实验则展示离散的测量结果。

## 三、角动量的叠加（4.4.3）

### 1. 总角动量

当一个系统具有多个角动量自由度时，可以将它们组合成总角动量。例如，轨道角动量与自旋角动量的组合：

`Ĵ = L̂ + Ŝ`

对于两个角动量量子数 j₁、j₂，总角动量量子数 j 的允许取值为：

`j = |j₁ − j₂|, |j₁ − j₂|+1, …, j₁+j₂`

总角动量 z 分量的量子数满足 `m = m₁ + m₂`。

**核心理解：** 角动量叠加不是简单地将两个角动量的大小相加，而是通过量子力学的角动量代数确定新的总角动量本征态及本征值。

### 2. 单重态与三重态

两个自旋 1/2 粒子的自旋空间共有四个独立基态，按照总自旋可以重新组合为一个单重态和三个三重态。

| 总自旋态 | 总自旋量子数 s | 归一化本征态 |
| --- | --- | --- |
| 三重态 | 1 | `|↑↑⟩` |
| 三重态 | 1 | `(|↑↓⟩ + |↓↑⟩)/√2` |
| 三重态 | 1 | `|↓↓⟩` |
| 单重态 | 0 | `(|↑↓⟩ − |↓↑⟩)/√2` |

单重态的总自旋为零；三重态具有非零总自旋，并对应三个允许的总自旋 z 分量。中间两个 m=0 的态虽然都由相同的直积基态构成，但相对相位不同，因此总自旋不同。

### 3. Clebsch–Gordan 系数

Clebsch–Gordan（CG）系数用于将单个角动量的直积基底转换为总角动量的共同本征态基底。上述单重态和三重态中的 1/√2 就是相关系数的具体例子。

**核心理解：** 角动量耦合在数学上是复合量子系统中的基底变换，CG 系数是对应的展开系数。基底变换本身不等于系统发生了物理相互作用。

## 四、与材料计算的联系

| 概念 | 材料计算中的应用 |
| --- | --- |
| 自旋态与泡利矩阵 | 自旋极化能带、自旋相关紧束缚哈密顿量 |
| 自旋磁矩 | DFT 中的自旋磁矩分析 |
| Zeeman 相互作用 | 外磁场调控磁性 |
| Larmor 进动 | 自旋动力学的基础 |
| 轨道角动量与自旋 | SOC 模型，例如 `ĤSOC = λ L̂ · Ŝ` |
| 单重态与三重态 | 理解两电子自旋态及磁交换模型 |

## 五、本节总结

**自旋自由度 → 自旋算符与泡利矩阵 → 自旋测量 → 磁场中的自旋 → 角动量叠加。**

本节重点是理解自旋是粒子的内禀角动量，泡利矩阵是自旋算符的矩阵表示，外磁场能够改变自旋能级及其动力学行为，而角动量叠加可以将多个角动量自由度组合为总角动量本征态。

4.3 节与 4.4 节的共同基础是角动量代数；两节内容共同为理解磁矩、磁交换及自旋轨道耦合提供理论基础。
