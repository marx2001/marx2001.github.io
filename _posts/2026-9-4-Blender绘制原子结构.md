本文记录如何将第一性原理计算得到的晶体结构文件，通过 **VESTA → Blender**
转换为适用于论文 Figure 的三维原子结构模型。

该流程面向没有 Blender 使用经验的科研人员，目标是：

``` text
POSCAR/CONTCAR
        ↓
VESTA 结构检查与显示优化
        ↓
导出模型文件
        ↓
Blender 三维渲染
        ↓
得到论文级原子结构示意图
```

核心思想：

``` text
VESTA负责晶体结构准确性
Blender负责三维表现、光照和渲染效果
```

不要直接在 Blender
中手动搭建晶体结构。对于二维材料和异质结构，原子坐标、键连接和周期性必须由晶体软件保证。

------------------------------------------------------------------------

# 一、整体工作流概览

## Step 1：准备结构文件

输入文件：

``` text
POSCAR
CONTCAR
CIF
```

推荐使用：

``` text
CONTCAR
```

原因：

-   已经过结构优化；
-   原子位置更加稳定；
-   可直接用于论文结构展示。

------------------------------------------------------------------------

## Step 2：VESTA处理结构

VESTA主要完成：

``` text
导入晶体结构
→
检查原子位置
→
设置键连接
→
调整原子显示比例
→
扩胞
→
导出模型
```

VESTA不建议作为最终渲染工具，而作为结构准备工具。

------------------------------------------------------------------------

# 二、VESTA结构处理步骤

## 1. 导入结构

打开：

``` text
File → Open
```

加载：

``` text
POSCAR/CONTCAR/CIF
```

检查：

-   元素种类；
-   原子数量；
-   晶格参数；
-   层间结构。

------------------------------------------------------------------------

## 2. 扩胞

二维材料通常需要扩胞显示周期性。

路径：

``` text
Edit
→
Edit Data
→
Unit Cell
```

设置：

例如：

``` text
a = 3
b = 3
c = 1
```

得到：

``` text
3×3×1 supercell
```

注意：

不要在 Blender 中直接扩胞。

原因：

-   周期关系难以控制；
-   键连接容易错误；
-   模型容易出现断键。

------------------------------------------------------------------------

## 3. 设置原子和键

建议：

显示主要化学键：

例如：

``` text
Cr-Se
Ru-Br
```

关闭不必要连接：

例如：

``` text
vdW界面弱相互作用
```

原则：

结构展示不是显示所有可能连接，而是突出晶体骨架。

------------------------------------------------------------------------

## 4. 调整原子比例

VESTA默认原子大小通常偏小。

论文图建议：

-   磁性元素适当放大；
-   配位原子保持比例；
-   键不要过粗。

------------------------------------------------------------------------

# 三、VESTA导出到Blender

## 推荐路线

``` text
VESTA
↓
VRML (.wrl)
↓
Blender
```

原因：

VRML可以保留：

-   原子球；
-   键；
-   基本颜色信息。

------------------------------------------------------------------------

导出：

``` text
File
→
Export Data
→
VRML
```

得到：

``` text
structure.wrl
```

------------------------------------------------------------------------

# 四、Blender导入流程（新手）

## Step 1：安装VRML导入插件

Blender 4.2默认可能没有VRML导入。

进入：

``` text
Edit
→
Preferences
→
Add-ons
```

搜索：

``` text
VRML
```

如果没有：

需要安装支持VRML/Web3D格式的插件。

------------------------------------------------------------------------

## Step 2：导入结构

菜单：

``` text
File
→
Import
→
VRML
```

选择：

``` text
structure.wrl
```

导入后：

模型会出现：

-   原子球；
-   键柱；
-   材质。

------------------------------------------------------------------------

# 五、Blender论文级调整流程

## 1. 设置Camera

不要直接使用默认Camera。

推荐：

``` text
添加 Camera
→
调整视角
→
Ctrl + Alt + NumPad 0
```

将当前视角绑定给Camera。

------------------------------------------------------------------------

## 2. Camera参数建议

二维异质结构推荐：

``` text
Lens:
35-70 mm
```

如果结构被裁剪：

降低焦距：

例如：

``` text
52 mm → 35 mm
```

------------------------------------------------------------------------

## 3. 画幅设置

横向二维材料推荐：

``` text
2400 × 1200
```

或者：

``` text
3000 × 1400
```

比例：

约2:1。

------------------------------------------------------------------------

# 六、常见问题与解决方法

## 问题1：渲染结果缺少一半结构

原因：

Camera视野太小。

解决：

检查：

``` text
Camera Lens
```

降低：

``` text
52 mm → 35 mm
```

或者：

增大Camera距离。

------------------------------------------------------------------------

## 问题2：Viewport视角和Camera视角不同

原因：

Viewport不是Camera。

解决：

当前满意视角：

执行：

``` text
Ctrl + Alt + NumPad 0
```

或者：

``` text
View
→
Align View
→
Align Active Camera to View
```

------------------------------------------------------------------------

## 问题3：原子之间键断裂

原因：

键长阈值设置错误。

解决：

在VESTA重新设置bond距离。

不要在Blender中手动连接大量键。

------------------------------------------------------------------------

## 问题4：结构颜色灰暗，没有质感

原因：

Blender默认材质和VESTA不同。

解决：

调整：

### Color Management

推荐：

``` text
View Transform:
Standard
```

增加：

``` text
Exposure:
+0.2~0.4
```

------------------------------------------------------------------------

## 问题5：结构过于稀疏

原因：

-   原子半径过小；
-   键过细。

解决：

增加：

``` text
Atom radius:
1.2-1.4倍
```

增加：

``` text
Bond radius:
1.1-1.2倍
```

------------------------------------------------------------------------

## 问题6：没有VESTA的球体质感

原因：

VESTA采用简单Phong光照，而Blender使用PBR材质。

解决：

Blender中：

降低Metallic：

``` text
Metallic ≈ 0
```

调整：

``` text
Roughness:
0.2-0.4
```

增加Specular效果。

------------------------------------------------------------------------

# 七、推荐Blender渲染设置

## 材质原则

原子不要设置为金属。

推荐：

``` text
Metallic:
0

Roughness:
0.2-0.4
```

类似VESTA的塑料球效果。

------------------------------------------------------------------------

## 灯光

推荐三点布光：

``` text
Key Light
主光

Fill Light
补光

Rim Light
轮廓光
```

或者：

一个大面积Area Light + 环境光。

------------------------------------------------------------------------

# 八、最终推荐流程总结

``` text
1. DFT得到POSCAR/CONTCAR

2. VESTA打开结构

3. 检查元素、晶格和层结构

4. 扩胞

5. 设置bond

6. 导出VRML

7. Blender导入

8. 调整Camera

9. 调整材质和灯光

10. 高分辨率渲染

11. Illustrator排版
```

------------------------------------------------------------------------

# 九、最终原则

``` text
结构准确性：
VESTA保证

视觉表现：
Blender完成

论文排版：
Illustrator完成
```

对于二维磁性异质结构：

推荐采用：

``` text
VESTA + Blender + Illustrator
```

作为论文 Figure 制作流程。
